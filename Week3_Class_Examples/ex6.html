7 Ways to Define Colours in CSS

Hover over any color value in VS Code to open the interactive color picker!

1. Named Colour

background-color: crimson;
Solid

2. 6-Digit Hex (#RRGGBB)

background-color: #0056b3;
Solid

3. 3-Digit Hex (#RGB)

background-color: #f60; /* #ff6600 */
Solid

4. RGB Method

background-color: rgb(40, 167, 69);
Solid

5. RGBA (with Alpha)

background-color: rgba(40, 167, 69, 0.5);
50% Transparent

6. HSL Method

background-color: hsl(280, 70%, 50%);
Solid

7. HSLA (with Alpha)

background-color: hsla(280, 70%, 50%, 0.5);
50% Transparent
