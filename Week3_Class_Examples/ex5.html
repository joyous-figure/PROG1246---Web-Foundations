CSS Sizing Units in Action

Resize the browser window to watch how each unit reacts!

1. Absolute: Pixels (px)

Fixed width of 300px. It ignores screen size and parent width.

width: 300px (Fixed)

2. Relative: Percentage (%)

Calculated relative to its immediate parent. Inside this dashed box (which is 80% wide), this blue bar takes up 50% of that space.

Dashed Parent Container (width: 80%)
width: 50% (of parent)

3. Relative: Typography (rem vs em)

rem looks at the root (<html>, usually 16px). em looks at its direct parent.

font-size: 1.25rem (1.25 × 16px = 20px)
Parent font-size = 20px
font-size: 1.5em (1.5 × 20px = 30px)

4. Viewport Units: (vw)

Tied directly to the browser window. 50vw is always exactly 50% of the entire screen width, regardless of what parent container it lives inside.

width: 50vw (50% of Viewport Width)
